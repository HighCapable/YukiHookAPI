YukiBaseHooker

abstract class YukiBaseHooker : PackageParam

Base hooker implementation for YukiHook. Inherit this class to organize multiple hooker feature modules in a single Xposed module.

See YukiHookLibXposedEntry or YukiHookXposed82Entry for the entry-point configuration.
