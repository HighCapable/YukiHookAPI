YukiHookLibXposedEntry

@Target(allowedTargets = [AnnotationTarget.CLASS])
annotation class YukiHookLibXposedEntry(val entryClassName: String = "", val minApiVersion: Int = 101, val targetApiVersion: Int, val scope: Array<String> = [], val staticScope: Boolean = false, val hotReload: YukiHookLibXposedEntry.HotReload = HotReload.NONE, val javaEntries: Array<KClass<*>> = [], val nativeEntries: Array<String> = [])

Marks the YukiHook libxposed entry class for code generation.

Requires yukihook-runtime-libxposed. Missing, conflicting, or mismatched runtimes will cause KSP to reject the build.

For the legacy Xposed Framework API, use YukiHookXposed82Entry with yukihook-runtime-xposed82 instead.

  • KSP generates java_init.list, module.prop, and scope.list under META-INF/xposed as build resources. native_init.list is also generated when nativeEntries is not empty.

  • The framework reads the module name and description from the application's standard android:label and android:description attributes, not legacy xposed* meta-data or module.prop. KSP does not generate or modify the AndroidManifest.

  • HotReload.MANUAL and HotReload.AUTO rebuild module hooks without restarting the host. Completed host lifecycle events are not replayed. Modules must release their own threads, native hooks and external callbacks before accepting a reload. Requests can be refused while managed callbacks or module activities are active, or after legacy resource-path injection. A host that has not loaded a reload-enabled module instance still needs to restart once.

The generated java_init.list lists the YukiHook entry first, followed by javaEntries. Its YukiHook entry uses the fully qualified annotated class name + _YukiHookXposedInit, or entryClassName.

  • Entry files are generated per build variant. Do not add duplicate entries under the source directory.

  • The annotated class must implement YukiHookXposedModule.

  • Exactly one hook entry may use either entry annotation. Multiple entries produce a compile-time error.

Parameters

entryClassName

the generated Xposed entry class name, or an empty string to use entry class name + _YukiHookXposedInit.

minApiVersion

minimum framework API version, at least 101.

targetApiVersion

targeted API behavior, independently of the compile-only API dependency.

scope

scope packages. An empty array declares no recommended scope. Use system explicitly for system_server.

staticScope

whether scope selection is restricted to the declared list.

hotReload

the module reload policy, HotReload.NONE by default. HotReload.MANUAL and HotReload.AUTO require targetApiVersion at least 102 and an empty javaEntries list. An incoming reload is completed when the new module instance declares HotReload.NONE with targetApiVersion at least 102.

javaEntries

additional native libxposed API Java entries extending XposedModule. These entries use their own framework callbacks and must keep their class names when R8 obfuscation is enabled.

nativeEntries

native entry library filenames, such as libexample.so, one per generated line. Empty disables generation of native_init.list. Package these libraries in the module APK, the framework loads them as native entries.
