YukiHookXposedModule

interface YukiHookXposedModule

Xposed module entry point for YukiHook.

Annotate the implementation with YukiHookLibXposedEntry for modern or YukiHookXposed82Entry for legacy to match the selected runtime.

onInit is called automatically while YukiHook initializes, and onHook is called automatically when hook loading starts.

Call YukiHook.configure or configure from onInit, and YukiHook.encase or encase from onHook.
