remember

inline fun <T> remember(key: String, noinline block: () -> T): T

Retains a value across module instances.

With YukiHookLibXposedEntry.HotReload enabled, the same key and declared result type reuse the saved result without running block. Otherwise block runs every time and nothing is retained, so the same declarations work on every runtime. Keys must be non-blank and unique in the current package scope, the same key can be used in different package scopes.

A change to the declared result type, its type arguments or nullability invalidates the saved result and runs block again.

For example, changing Int to String or List<Int> to List<String> recomputes the value even with the same key. The cache type is the inferred or explicit T, not the runtime class of the value.

Change key when the calculation changes but the declared result type stays the same. Values must not refer to classes compiled into the module, including its packaged dependencies such as the Kotlin standard library, e.g. module classes, Pair, Unit or function types, either directly or inside collections, maps and Class values. Platform, host and compileOnly dependency classes are supplied by other class loaders and can be retained.

Collection and map results, including nested ones, are frozen into read-only snapshots, only their elements are checked. Declare them as read-only List, Set, Map, Collection or Iterable, and do not modify them after they are returned. Arrays, Bundle and reference holders such as WeakReference, AtomicReference or ThreadLocal cannot be frozen and are rejected. Keep hook registration and other actions that must run after reload outside block.

Call it only while declaring hooks, e.g. in onHook or loadApp, not in hook callbacks, lifecycle callbacks or other threads.

Examples:

val title = remember("host-title-v1") {
    "$packageName ($processName)"
}
val method = remember("activity-onCreate-v1") {
    Activity::class.java.getDeclaredMethod("onCreate", Bundle::class.java)
}

method.hook {
    after {
        instance<Activity>().title = title
    }
}
