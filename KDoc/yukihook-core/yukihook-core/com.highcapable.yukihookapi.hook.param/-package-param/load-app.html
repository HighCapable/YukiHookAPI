fun loadApp(name: String, block: PackageParam.() -> Unit)

Loads and hooks apps with the specified package name.

Parameters

name

the package name. An empty name matches all apps, the system server is not included. "android" or "system" refers to the system framework and works as loadSystem.

block

the PackageParam hook block.

fun loadApp(vararg name: String, block: PackageParam.() -> Unit)

Loads and hooks apps with the specified package names.

Parameters

name

the package names. If every name is empty, all apps are matched, otherwise empty names are ignored. The system server is not included. "android" and "system" are not allowed here, use loadSystem for the system framework.

block

the PackageParam hook block.

See also

loadSystem

Throws

IllegalArgumentException

if name contains "android" or "system".

fun loadApp(excludeSelf: Boolean = false, block: PackageParam.() -> Unit)

Loads and hooks all apps, the system server is not included.

All apps include every package loaded into a process, a process may load packages other than its host, use isFirstApplication to check whether the current package is the host of the process.

Parameters

excludeSelf

whether to exclude the module itself, false by default. When enabled, the hosts do not include the current module.

block

the PackageParam hook block.
