HookChain

class HookChain : HookInvocation

Invocation context for a chain interceptor.

Return a value to complete the invocation, or call proceed to continue the remaining chain. Uncaught exceptions propagate to the caller. This context must not be shared across threads or used after the interceptor returns or throws.

Parameters

dataExtraStorage

the storage shared by this interceptor's invocations.
