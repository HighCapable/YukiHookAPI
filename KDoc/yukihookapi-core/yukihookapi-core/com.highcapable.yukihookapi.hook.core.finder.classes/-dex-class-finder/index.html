DexClassFinder

class DexClassFinder : ClassBaseFinder

Deprecated

YukiHookAPI will completely remove the API of its own reflection part in version 2.0.0. We recommend that you use KavaRef to implement reflection for better performance and maintainability. See: https://github.com/HighCapable/KavaRef

Class finder.

Uses BaseDexClassLoader to find a specified Class or group of Class instances by specified conditions.

  • This feature is still experimental. Performance and stability issues may remain. Report any issues you encounter and help us improve it.

Parameters

name

the name identifying the current Class cache. Caching is disabled when omitted. Enabling caching requires async.

async

whether asynchronous lookup is enabled.

loaderSet

the current ClassLoader instance.
