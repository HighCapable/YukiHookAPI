Yuki Hook

A modern hook API and Xposed module solution

Get Started
Changelog
🧩

Xposed Module Develop

The compiler handles the entry classes and configuration files of Xposed modules for every base module in one place, a single entry is all you need to finish the configuration.

🪶

Light and Elegant

Simple to configure and ready to use, with a Kotlin DSL that builds the hook flow as a chain, your code is your business logic, what you see is what you get.

🐞

Debugging Efficient

Rich debug logs and exception handling, down to the name and exception type of each hooked method, help you debug and find errors quickly.

🔄

Fully Compatible

The same hook code runs on both the classic Xposed 82 and libxposed 101+, and the core features migrate without loss by switching the base module.

🛡️

Obfuscate Support

The built Xposed module simply supports R8, obfuscate will not destroy the hook entry point, and no other configuration is required under R8.

⚡

Quick to Start

Simple and easy to use it now. Do not need complex configuration and full development experience, Integrate dependencies and enjoy yourself.

All Hook process in one step, everything is simplified ​

kotlin
loadApp("io.github.myapp") {
    val demoClass = Demo::class.java
    val setGreeting = demoClass.getDeclaredMethod(
        "setGreeting", String::class.java
    )

    setGreeting.intercept {
        proceed(arrayOf("Hello, Yuki Hook!"))
    }
}
kotlin
loadApp("io.github.myapp") {
    val demoClass = Demo::class.java
    val setGreeting = demoClass.getDeclaredMethod(
        "setGreeting", String::class.java
    )

    setGreeting.hook().before {
        firstArg().set("Hello, Yuki Hook!")
    }
}
